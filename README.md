# صفحه‌خوان (ScreenReader)

خواندن با صدای متن هر اپلیکیشن روی اندروید: صفحه وب، پیام‌رسان، اخبار، PDF و کتاب الکترونیک.
متن‌های تصویری (PDF اسکن‌شده، عکس) با OCR آفلاین فارسی/انگلیسی (Tesseract) خوانده می‌شوند.

## ساخت APK
1. پوشه را در یک ریپوی GitHub آپلود کنید.
2. تب Actions → اجرای «Build APK» (با هر push خودکار اجرا می‌شود).
3. از بخش Artifacts فایل `ScreenReader-apk` را دانلود و نصب کنید.

## راه‌اندازی روی گوشی
1. برنامه را باز کنید → «باز کردن تنظیمات دسترسی‌پذیری» → «صفحه‌خوان (دکمه شناور)» را روشن کنید.
2. اگر پیام «تنظیمات محدودشده» آمد: «اطلاعات برنامه» → منوی ⋮ → «Allow restricted settings» → دوباره مرحله ۱.
3. در بخش «موتور صدا» مطمئن شوید پیام ✅ فارسی نمایش داده می‌شود.

## ساختار
- `ReaderService.kt` — سرویس دسترسی‌پذیری + دکمه شناور + خواندن پیوسته
- `ScreenTextExtractor.kt` — استخراج متن از درخت عناصر صفحه
- `OcrEngine.kt` — تشخیص متن از تصویر صفحه (Tesseract، مدل best فارسی)
- `Speaker.kt` — TTS جمله‌به‌جمله با مکث/ادامه و تشخیص خودکار زبان
- `ProcessTextActivity.kt` — «بلند بخوان» در منوی انتخاب متن
- `keystore/debug.jks` — کلید امضای ثابت تا نسخه‌های بعدی روی قبلی نصب شوند
