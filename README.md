# محاسبه‌گر طول برش پیلگر (اپ اندروید)

نسخه اندروید اپ «محاسبه‌گر طول برش پیلگر» که با Capacitor ساخته شده است. فایل APK به‌صورت خودکار روی GitHub Actions ساخته می‌شود.

## ساختار
- `www/index.html` : خود اپ (همان فایل HTML؛ فرمول‌ها و محاسبات بدون تغییر)
- `www/fonts/` : فونت‌ها به‌صورت محلی، برای کار کردن کاملاً آفلاین
- `assets/` : آیکون و اسپلش (برای تغییر آیکون، این PNGها را عوض کنید)
- `keystore/pilgercut.jks` : کلید امضای ثابت، برای اینکه نسخه‌های بعدی به‌صورت آپدیت نصب شوند و تاریخچه پاک نشود. **این فایل را حذف یا عوض نکنید.**
- `scripts/patch-android.js` : تنظیمات اندروید (رنگ نوارها، شماره نسخه، امضا)
- `.github/workflows/build-apk.yml` : ساخت خودکار APK

## ساخت APK
با هر Push روی شاخه `main`، یا از تب **Actions → Build Android APK → Run workflow**.
فایل APK در بخش **Releases** مخزن قرار می‌گیرد.

## آپدیت اپ
فقط `www/index.html` را با نسخه جدید جایگزین کنید (خط فونت‌ها و بخش خروجی گرفتن نسخه اندرویدی را نگه دارید) و Commit کنید.
